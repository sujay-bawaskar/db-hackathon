# Scoring Rubric

Score each idea 1-5 on every dimension. Total = sum. Use the notes column to
justify non-obvious scores.

| Dimension          | 1                                  | 5                                       | Weight |
|--------------------|------------------------------------|-----------------------------------------|--------|
| Judge appeal       | niche, hard to demo                | obvious "wow" in <30s                   | x1     |
| Feasible in time   | needs weeks                        | shippable in the hackathon window       | x2     |
| AI is core         | AI bolted on                       | impossible without the AI piece         | x2     |
| GCP fit            | GCP is incidental                  | leans on a GCP differentiator           | x1     |
| Originality        | done many times                    | fresh angle / underserved audience      | x1     |
| Real-world value   | toy                                | solves a real pain someone would pay    | x2     |
| Data availability  | no data, can't fake it             | data in hand or trivially synthesizable | x1     |

## Scorecard

| Idea | Judge | Feasible | AI-core | GCP-fit | Orig | Value | Data | Weighted total | Notes |
|------|-------|----------|---------|---------|------|-------|------|----------------|-------|
|      |       |          |         |         |      |       |      |                |       |

## Decision rule

- Top weighted total wins, unless two are within 2 points — then judge-appeal
  breaks the tie.
- Any idea scoring 1 on Feasible-in-time is automatically disqualified.
