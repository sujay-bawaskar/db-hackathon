# Agent Name Vote — Ship-It Agent rename

Date: 2026-07-18
Status: Open for team vote

## Why rename

"ShipIt" reads as a startup trope, not a bank tool. We want a name that is:

- Pronounceable and spellable over the phone.
- Free of filler descriptors ("AI", "Global", "Realtime").
- Evokes release readiness, not a generic dev tool.

## The five candidates

### 1. Herald
A messenger that carries the change request through the SDLC gates and
announces the release. Two syllables, easy to spell.
**Vibe:** trusted courier, formal but human.

### 2. Manifest
A release manifest is a real banking/ops term — the package of evidence that
accompanies a deployment. The agent assembles it.
**Vibe:** domain-native, concrete, no fluff.

### 3. Greenlight
The moment every release waits for. The agent gets you to approval.
**Vibe:** outcome-oriented, two syllables, memorable demo line ("give it the
greenlight").

### 4. Docket
A docket is the bundle of documents presented for review — exactly what the
agent produces (release note, risk, evidence, approval request).
**Vibe:** legal/compliance flavor, fits a regulated bank.

### 5. Steward
A steward manages something responsibly on someone's behalf. Evokes
governance and care, not speed-for-speed's-sake.
**Vibe:** trust, oversight, controlled release.
